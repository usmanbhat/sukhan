# Sukhan optional poet packs

This public repository hosts the optional SQLite poet packs for Sukhan. Rumi and Saadi are already bundled in the app, so their database files are not included here.

| Poet | Poems | Download |
| --- | ---: | --- |
| Hafez | 695 | [hafez.sqlite](https://raw.githubusercontent.com/usmanbhat/sukhan/main/hafez.sqlite) |
| Iqbal | 972 | [iqbal.sqlite](https://raw.githubusercontent.com/usmanbhat/sukhan/main/iqbal.sqlite) |
| Amir Khusro | 2,198 | [khosro.sqlite](https://raw.githubusercontent.com/usmanbhat/sukhan/main/khosro.sqlite) |

The [manifest](https://raw.githubusercontent.com/usmanbhat/sukhan/main/manifest.json) contains pack metadata, source labels, checksums, and bundled-in-app flags. It is included unchanged; it also records Rumi and Saadi, even though their SQLite files are not part of this repository.

## Source notes

The manifest identifies the source as the “Ganjoor public poetry export” and preserves the source labels and revision metadata. Its reuse note describes the Ganjoor project introduction as calling the database public-domain/open-source. This README does not make a separate or stronger license claim; consult the source project and its notices for reuse guidance.

The direct file URLs above can be used when wiring optional pack downloads into the app.
